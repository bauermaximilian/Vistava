# Quickstart

To get you started with using Vistava quickly without having to read too much, check out the following video clips that demonstrate how to navigate the application quickly when reading a comic, looking at pictures or watching a video. The pressed keys or mouse interactions are shown at the bottom of the screen.

## Keyboard navigation

[filename](../media/quickstart-keyboard.mp4 ':include :type=video controls width=100%')

#### Thumbnail view

- Move selection: <kbd>&uarr; Up</kbd>, <kbd>&darr; Down</kbd>, <kbd>&larr; Left</kbd>, <kbd>&rarr; Right</kbd> (hold <kbd>&uarr; Up</kbd>/<kbd>&darr; Down</kbd> to scroll)
- Open selected tile in detail view: <kbd>&#8996; Enter</kbd>
- Open selected tile in file explorer/web browser: <kbd>&#8679; Shift</kbd>+<kbd>&#8996; Enter</kbd>
- Go to previous directory: <kbd>&#9003; Delete</kbd>

#### Detail view

- Leave detail view: <kbd>&#9003; Delete</kbd>
- Toggle zoom modes: <kbd>&#8679; Shift</kbd>
- Zoom in or out (in steps): <kbd>+ Plus</kbd>, <kbd>- Minus</kbd>
- Move view (while zoomed-in): <kbd>&uarr; Up</kbd>, <kbd>&darr; Down</kbd>, <kbd>&larr; Left</kbd>, <kbd>&rarr; Right</kbd>
- Start/pause video playback: <kbd>&#9251; Space</kbd>
- Change video volume (during playback): <kbd>&uarr; Up</kbd>, <kbd>&darr; Down</kbd>
- Seek forward/backward (during playback): <kbd>&larr; Left</kbd>, <kbd>&rarr; Right</kbd>
- Mute video (during playback): <kbd>M</kbd>

## Mouse navigation

[filename](../media/quickstart-mouse.mp4 ':include :type=video controls width=100%')

#### Thumbnail view

- Open tile in detail view: <kbd>LMB</kbd> (Left mouse button)
- Open tile in file explorer/web browser: <kbd>MMB</kbd> (Middle mouse button)
- Scroll: Mouse wheel up/down
- Go to previous directory: <kbd>BMB</kbd> (Back button on mouse)
- Go to next directory: <kbd>FMB</kbd> (Forward button on mouse)

#### Detail view

- Leave detail view: <kbd>BMB</kbd> (Back button on mouse)
- Toggle zoom modes: <kbd>RMB</kbd> (Right mouse button)
- Zoom in or out (to cursor position): Mouse wheel up/down 
- Move view (while zoomed in): Hold and drag <kbd>LMB</kbd> (Left mouse button)
