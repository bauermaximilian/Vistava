# Vistava Documentation

Welcome to the documentation of Vistava, the free open-source multimedia viewer!

<p align="center">
  <img src="media/screenshot.png" alt="Vistava screenshot" />
</p>

Vistava is a calm, minimalist viewer for images and videos. Vistava makes browsing your media
simple - on any device.

- Browse your image and video library without distractions
- Use a mouse, keyboard, touch screen, or gamepad
- Share your library within your local network
- Open the same interface on a TV, smartphone, tablet, or VR headset
- Extend the app with community-built integrations for third-party sources

## About Vistava

The name "Vistava" comes from the Czech word "výstava" (pronounced ˈviːstava), meaning "exhibition" or "gallery" - which should both hint at the calm, distraction-free gallery aspect as well as the network sharing capabilities of the application. Pretty smart, isn't it?

### Project history

Vistava began as a university project in 2020. I kept it as a personal side project after I graduated and slowly developed it into a stable application that I wanted to share. If you encounter bugs or problems, feel free to create issues on GitHub.

### Usage of AI

The source code of the Vistava application itself was written entirely without the use of AI. GitHub Copilot (free tier) was used for proofreading the (human-written) texts of this documentation and the website, as well as for helping with the design of the latter. 

### Privacy

Vistava has no ads, analytics or user tracking, requires no subscriptions, does not depend on any cloud services or CDNs and can be used offline without internet access (until you decide to install extensions that pull media from the internet, of course). Vistava does not expose your data to the internet - even when the "local network sharing" feature is enabled (but please read the [related documentation](/3-usage?id=local-network-sharing) for information on how to use this feature safely!)
