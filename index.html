Why should you use it

I just think it's neat!

01

Built for your files

Browse your local image and video library in a simple masonry-like layout without distractions or additional noise. No cloud, no AI stuff, no bloat - yes, that still exists.

02

Mouse, keyboard, touch, or gamepad

It works naturally with the input method you prefer. Keyboard-only, mouse-only, touch screens, and even gamepads - whatever use-case, Vistava got you.

03

Share on your local network

Start the desktop app, enable the optional sharing feature, and open the generated URL on any browser on the same network - no flash drives or cloud storage required.

04

Open to extension

The app is fully open-source and can be expanded with community-built extensions for image boards or web comics, as long as they have a HTTP API.

So much options

Navigate how you want

Whether you prefer keyboard shortcuts, mouse navigation, touch input, or even a gamepad, Vistava is designed to feel intuitive and non-frustrating - no matter what input method you prefer.

And if you don't like the default keybindings, worry not - these can be customized through configuration files. Yes, this isn't peak user experience, but you're not gonna do that so often and it's documented, so… you'll manage.

Local network sharing

From your PC to your TV, smartphone, or VR headset.

Enable the network sharing from the desktop app and Vistava generates a temporary HTTP URL. Enter that on another device in the same network (private WiFi or LAN) with a somewhat modern web browser or scan the QR code shown in the app.

That second device will then show the same UI and the same media library, so you can watch all your images or movies on a Smart TV, tablet, phone, or VR headset without moving files around or going through some cloud service.
